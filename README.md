# Thực hành: Danh sách trong CSS

## Cách chạy
1. Giải nén thư mục dự án.
2. Mở `index.html` bằng trình duyệt.
3. Để hình ảnh dấu đánh dấu hiển thị đúng, giữ nguyên thư mục `images` cùng với `index.html` và `style.css`.

## Nội dung đã thực hiện
- `list-style-type: square`
- `list-style-type: upper-roman`
- `list-style-image` dùng ảnh SVG cục bộ
- So sánh `list-style-position: outside` và `inside`
- Thuộc tính rút gọn `list-style`
- Màu nền, màu chữ, `padding`, `margin`
- Danh sách tổng hợp “Lộ trình học lập trình Web”

## Đưa lên GitHub
1. Tạo repository mới trên GitHub.
2. Tải lên `index.html`, `style.css`, thư mục `images/` và `README.md`.
3. Nếu muốn trang web truy cập được bằng đường dẫn, vào **Settings → Pages**, chọn nhánh `main` và thư mục `/ (root)`, rồi lưu.
