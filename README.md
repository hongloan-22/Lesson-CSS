# Thực hành: Bảng trong CSS

## Cách mở
1. Giải nén gói dự án.
2. Mở `index.html` bằng trình duyệt.
3. Giữ `index.html` và `style.css` cùng một thư mục.

## Nội dung đã thực hiện
- `border` cho bảng và các ô.
- `border-collapse: collapse` để gộp đường viền.
- `width` và `height` cho bảng/hàng.
- `text-align` và `vertical-align`.
- `padding` cho các ô.
- `background-color` và `color`.
- Bảng có hàng xen kẽ màu nền, hiệu ứng rê chuột và bố cục cuộn ngang trên màn hình nhỏ.

## Nộp lên GitHub
1. Tạo repository mới trên https://github.com/
2. Tải lên `index.html`, `style.css`, `README.md`.
3. Nhấn **Commit changes**.
4. Muốn xuất bản trang web, vào **Settings → Pages**, chọn nhánh `main` và thư mục `/ (root)`, rồi lưu.
